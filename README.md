# Bulk Downloads

Save every attachment, GIF and embedded photo or video of a message at once from its long-press menu.

Long-press a message with attachments and tap **Download** (or **Download all** when there are several). Photos, GIFs and videos are saved the way Discord saves them; on iOS, other files open in the share sheet so you can keep them with **Save to Files**. Photos and videos shown in embeds (X posts, link previews) are included, without duplicates. A toast shows how many were saved.

## Install

Add this URL in **Settings → Plugins → Settings Icon → Repository URL**:

```text
https://raw.githubusercontent.com/dariussbezy/dariussbezy-Plugins/main/index.json
```

This repository holds the source and test builds of Bulk Downloads. All plugins are published together in [dariussbezy's Plugins](https://github.com/dariussbezy/dariussbezy-Plugins).
